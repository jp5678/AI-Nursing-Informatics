# AI융합 간호정보학 — 학습 플랫폼

청암대학교 간호학과 3학년 「AI융합 간호정보학」 교과목을 위한 반응형 웹 학습 플랫폼입니다.

## 주요 기능

- **홈 대시보드**: 교과목 소개, 전체 학습 진도(13개 장), 4부 구성(토대 → 임상 적용 → 시스템과 연구 → 통합 비전) 챕터 카드
- **머리말 / 맺음말**: 교재의 머리말과 '미래 간호사들에게 드리는 편지' 전문
- **장별 학습 화면**
  - 📖 학습: 학습목표(Bloom 분류 기반) + 핵심 개념 카드 + 검증된 핵심 출처
  - 🃏 용어 카드: 탭하면 뒤집히는 핵심 용어 플래시카드
  - ✍️ 복습 퀴즈: O/X + 5지선다, 즉시 채점과 해설, 장별 최고 점수 기록
  - ❓ Q&A: 학생이 흔히 갖는 질문과 학술적 답변 (1~2장)
- **진도 관리**: 장별 학습 완료 표시와 퀴즈 최고 점수를 브라우저(localStorage)에 저장
- **반응형 디자인**: 데스크톱 사이드바 ↔ 모바일 햄버거 메뉴 자동 전환

## 실행 방법

빌드 과정이 없는 정적 사이트입니다. 저장소를 받은 뒤 아무 정적 서버로 열면 됩니다.

```bash
# 예: Python 내장 서버
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages에 그대로 배포할 수 있습니다 (Settings → Pages → 브랜치 루트 선택).

## 구조

```
index.html      # 진입점
css/style.css   # 반응형 스타일
js/data.js      # 교재 데이터 (13개 장 + 머리말/맺음말)
js/app.js       # SPA 라우팅·렌더링·퀴즈·진도 저장 로직
```
